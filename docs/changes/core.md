# تغییرات جریان الف (هسته گفتگو و تسک صفر)

## تسک صفر (۴ آبان ۱۴۰۵)

جزئیات و دستور مایگریشن: `docs/tasks/00-task-zero.md`.

**تصمیم‌ها و اصلاح‌ها:**

- **اصلاح یک برداشت قبلی:** در طراحی اولیه نوشته بودم «هیچ‌چیز `IsDelete` را `true` نمی‌کند». درست نبود: `ApplicationDbContext` از قبل `Remove()` را به حذف نرم تبدیل می‌کرد. آنچه نبود، **زمان حذف** (`DeletedAt`) و یک متد صریح دامین بود. حالا هر دو راه هست.
- ایندکس یکتای مشتری از قبل وجود داشت (روی نام و فامیل خام و بدون توجه به حذف نرم). جایگزین شد با ایندکس روی نام نرمال‌شده و فقط برای رکوردهای حذف‌نشده.
- `CustomerService.CreateAsync` برای نام تکراری **خطا نمی‌دهد** و مشتری موجود را برمی‌گرداند (رفتار قبلی، که برای جریان گفتگو امن‌تر است). `CUSTOMER_ALREADY_EXISTS` فقط وقتی می‌آید که دیتابیس نقض یکتایی را گزارش کند (دو درخواست همزمان).
- `AppException` به Domain رفت (وابستگی لایه‌ها فقط به داخل).

**محدودیت:** Infrastracture و Api (پیکربندی EF، `UnitOfWork`، میدل‌ور، `Program.cs`) نوشته شده ولی تا build مدیر پروژه کامپایل نشده‌اند.
