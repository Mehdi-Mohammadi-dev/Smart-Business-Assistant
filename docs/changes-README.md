# تغییرات هر جریان

- `ledger.md`: تغییرات دفترکل و APIهای مرتبط.
- `platform.md`: امنیت، احراز هویت، اشتراک و زیرساخت API.

- `referrals.md`: API معرفی دوستان، وضعیت اشتراک دعوت‌شدگان و دسترسی `SystemAdmin`.

`docs/nlu/CHANGELOG.md` تاریخچهٔ NLU است و باید فقط هنگام تغییر جریان NLU به‌روزرسانی شود.
